# HyperVolumeANC

给澎湃 OS 4 的音量面板加一个更顺手的降噪按钮。

## 功能

- 在静音与勿扰之外新增一个音量面板实例按钮，一键切换耳机的降噪 / 通透 / 关闭
- 支持「降噪 ⇄ 通透」两态循环，也可以选「降噪 → 通透 → 关闭」三态循环
- 有应用正在播放声音时，音量条上方会多出一个分应用音量入口，点开可单独调节每个应用的音量；面板从右侧滑入滑出、卡片与滑块比例对齐原生风格，弹出时不再全屏模糊与压暗
- 小米声音自带的悬浮球不再显示（入口搬到音量条上方），仍保留实例用于点击回退
- 展开音量面板的耳机菜单可以直接断开已连接的耳机
- 切换到降噪或通透时显示超级岛提示（可在设置里关闭），切换到关闭不打扰
- 设置页可以重启作用域、查看三个作用域的连接状态与运行诊断（可一键复制诊断信息）、开关降噪 / 通透通知、隐藏桌面图标、切换语言 / 主题 / 底部导航栏样式，并内置更新检查

## 支持的耳机

| 品牌 | 支持方式 |
| --- | --- |
| Xiaomi（含 Redmi） | 系统原生支持 |
| Apple 耳机 | 系统原生支持 |
| Sony / Huawei 耳机 | 需要安装对应的 SonyPods / HuaweiPods 模块 |
| OPPO 耳机 | 需要安装 OppoPods，上游 Leaf-lsgtky 版本或 1812z 分支均可，两者接口一致 |

## 使用说明

- 作用域：`com.android.systemui`、`com.xiaomi.bluetooth` 与 `com.miui.misound`（分应用音量面板由音质音效提供），勾选后重启作用域
- 请只保留一个提供同类分应用音量功能的模块（例如 AppVolumeBarHook、Soundman）：同时开启可能出现两个入口或面板互相覆盖；本模块检测到 AppVolumeBarHook 的入口时会自动让位，但仍建议二选一
- OPPO 耳机由 OppoPods 模块接管，本模块读取它广播的降噪状态；模块没上报状态时不会显示降噪行
- 隐藏桌面图标后，可从模块管理器的「模块设置」进入本应用
- 只在小米 17 Pro Max 与红米 K90 Pro Max（小米澎湃 OS 4 Beta）上做过完整测试，其它机型可能存在差异
